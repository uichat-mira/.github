# UIChat Mira

**Local-first personal AI workspace.**

Mira is a desktop-first AI workspace for conversations, agents, tools, local files, remote capabilities, and personal workflows.

The project is evolving toward a simple goal:

> Start from chat, and eventually become something that can truly hold your work together.

## Projects

- **UIChat Mira Desktop** — Main desktop application
- **Mira Mobile** — Mobile companion with remote and direct API access
- **Mira Docs** — Documentation, product journal, and development notes
- **Mira Forge** — Agent-oriented coding and work environment
